# amazon-seller-data-analysis
Exploratory Data Analysis of a synthetic Amazon Seller dataset using Python, Pandas, and Matplotlib.

# 📊 Amazon Seller Data Analysis

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a synthetic Amazon Seller dataset.

The objective of this project is to understand seller information, identify patterns in the data, and practice data analysis using Python.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📂 Dataset

The dataset contains information about Amazon sellers, including:

- Seller ID
- Seller Name
- Country
- Product Category
- Total Products
- Average Product Price
- Seller Rating
- Review Count
- Fulfillment Method
- Years Active

Note: This is a synthetic dataset created for learning and practice purposes. It does not contain real Amazon seller data.

## 🔍 Exploratory Data Analysis

The analysis includes:

- Checking dataset shape and data types
- Identifying missing values and duplicate records
- Analyzing seller distribution across countries
- Finding the most common product categories
- Analyzing seller ratings
- Comparing average product prices across categories
- Analyzing fulfillment methods
- Finding top sellers based on products and reviews
- Comparing average seller ratings by country
- Analyzing sellers based on years of activity

## 📈 Key Skills Practiced

- Data Cleaning
- Data Exploration
- Pandas `groupby()`
- `value_counts()`
- Sorting and filtering data
- Aggregation using `mean()`
- Data Visualization using Matplotlib

## 📁 Project Files

- `amazon_seller_info.csv` - Dataset used for analysis
- `amazon_seller_analysis.ipynb` - Jupyter Notebook containing the complete EDA

## 🎯 Conclusion

This project helped me strengthen my understanding of Exploratory Data Analysis using Python. I practiced working with Pandas for data manipulation and Matplotlib for creating visualizations and extracting useful insights from seller data.
